# 補助金・税制改正チェッカー — 使い方

補助金・助成金や税制改正の「今使えるもの・締切・要件・要点」を一覧でき、
**業種を選ぶと「あなたが使える可能性がある制度」をまとめて教えてくれる**ツールです。
情報は毎週、自動で最新に更新されます。

---

## 1. 見る人（誰でもOK・Claude不要）

1. このフォルダの **`index.html`** をダブルクリックするだけ。
   （デスクトップに作った「補助金・税制改正チェッカー」のショートカットからでもOK）
2. 最初の画面 **「🎯 業種から探す」** で、自分の業種ボタンを押す。
   → 「あなたの業種向け」「全業種で使える」に分けて、補助金と関係する税制改正が並びます。
3. ほかに、上のタブで
   - **📋 補助金一覧** … すべての補助金を締切順・業種・状況で絞り込み
   - **🧾 税制改正** … 改正の要点・対象・影響度で確認
   ができます。

> インストール不要・インターネット接続なしでも閲覧できます。
> 各カードの「🔗 出典」から公式ページに飛べます。

---

## 2. 情報の自動更新（この仕組みの心臓部）

- **あなたのPC（Claude Code が入っているPC）** が、毎週決まった時刻に自動で
  公式サイトを調べて、データ（`data.js`）を最新化します。
- 更新のとき Claude がやることは **「公開情報を読みに行く」だけ**。
  会社の数字や個人情報を送ることは一切ありません（＝情報漏洩リスクを抑えた設計）。
- 「見る人」には Claude は不要です。あなたのPCが更新した結果を、みんなが `index.html` で見るだけ。

### すぐ最新にしたいとき（任意）
- **`今すぐ更新.bat`** をダブルクリック → 数分で最新化 → `index.html` を開き直す。

### 自動更新の時刻を変える・止める
Windowsの「タスクスケジューラ」を開き、**「補助金税制チェッカー_自動更新」** というタスクを探します。
- 時刻変更 … タスクを右クリック →「プロパティ」→「トリガー」
- 一時停止 … タスクを右クリック →「無効」
- 完全に削除 … タスクを右クリック →「削除」

---

## 3. 大事な注意（必ずお読みください）

- この一覧は **「早わかり用」** です。AIが公式情報を集めて要約しています。
- 申請・判断の前に、**必ず各カードの「🔗 出典（公式ページ）」と、税理士・専門家で確認**してください。
- 金額・締切・要件が確定していない項目は **「要確認」** と表示されます。

---

## 4. 他の人にも最新版を届けたいとき

このフォルダごと **共有フォルダ・OneDrive・SharePoint** に置けば、
あなたのPCが更新するたびに、みんなが最新の `index.html` を開けます。
（移した場合は、自動更新がそのフォルダを見るように設定し直します。声をかけてください。）

---

## 5. ファイルの説明（触らなくてOK）

| ファイル | 役割 |
|---|---|
| `index.html` | 見る画面（ダッシュボード）。ダブルクリックで開く |
| `data.js` | データ本体（補助金・税制改正の一覧）。自動更新で書き換わる |
| `update.ps1` | 自動更新の実行スクリプト |
| `update-prompt.md` | 更新時に Claude が読む指示書 |
| `今すぐ更新.bat` | 手動で今すぐ更新したい時に使う |
| `logs/` | 更新の実行記録（うまくいったか確認用） |

---

*このツールは「公開情報を取りに行くだけ」で動きます。実データ（社内情報）を入力する場面はありません。*
